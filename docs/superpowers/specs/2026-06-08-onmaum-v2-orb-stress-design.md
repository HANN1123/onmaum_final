## 1. 개요

온마음은 **콜센터 감정노동자가 본인 소유로 쓰는, 통화 부하를 부드럽게 비추고 회복을 돕는 도구**다. 카메라로 표정을 상시(백그라운드) 감지해 **스트레스 지수(긍정/스트레스 2축)**를 산출하고, 이를 **감정 오브**(비언어 시각)와 **오전/오후/퇴근 회고**로 돌려준다. 단정하지 않고 제안하며, 데이터는 기기에만 둔다.

이 문서는 교수 피드백 2차례(① 정확도 ② 내부4/화면축약 ③ 개인화 개입 ④ 통화 시연 / A 스트레스 지수 2축+피드백 재검토 B 회원가입 설문 개인화 C 오브 오버레이)와, 비주얼 컴패니언으로 함께 다듬은 오브 디자인을 통합한다.

### 타깃 사용자
- 1차 사용자: **콜센터 상담원 본인** (자발적 설치·사용). 관리자/고용주 대상 아님.

## 2. 핵심 원칙

1. **단정하지 않는다.** "당신은 화났습니다" 금지. 질문형·상황귀인·비언어로 표현. (affect labeling 역효과)
2. **노동자 소유.** 데이터는 기기에만(서버·계정·관리자뷰·내보내기 없음). 본인만 본다.
3. **추정임을 인정한다.** 표정→감정 추론은 자주 틀린다. 불확실성을 고지하고, self-report로 보정한다.
4. **무표정 ≠ 소진.** 상담원의 무표정은 직무(감정 연기)이지 스트레스가 아니다. flatAffect를 위험 지표로 쓰지 않는다.
5. **과개입 금지.** 통화마다 끊고 들어가지 않는다. 앰비언트 + 주기적 회고 + (옵트인) 넛지.

## 3. 감정 인식 (정확도 보강)

기반: 현행 `face-api.js`(상시 배경, 0.5초 폴링). face-api의 angry 약점 보강:

- **즉시(P0):**
  - 버리던 `disgust`를 부정/적대 버킷에 합침 (이미 face-api가 출력)
  - angry **임계값을 낮춰** 약한 화남도 포착, **시간 스무딩** + **지속 게이트**(아래 §4)
- **후순위(P6):** `onnxruntime-web` + HSEmotion EfficientNet-B0(AffectNet, 감정+valence-arousal)로 모델 교체. 앰비언트+집계 모델이라 per-frame 정확도 의존이 낮아 우선순위 낮음.

내부 분류는 4감정(happy/calm/sad/angry)을 유지하되, **사용자에게 이산 감정 라벨 막대(EmotionDisplay)는 노출하지 않는다.** 교수 피드백 ②("내부 풍부 / 화면 단순")의 정신은 **오브(연속·비언어) + 2축 지수 + 한 줄 카피**로 충족한다.

## 4. 스트레스 지수 (2축 알고리즘) — 핵심

교수 지시: "스트레스 지수를 산출해 긍정·부정 2개를 낸다." **긍정 P**와 **스트레스 N**을 독립 2축으로 산출한다(PANAS 원리 — 긍정·부정은 한 축의 양 끝이 아니라 독립). face-api 감정값은 합이 1이라 단순 합산하면 한 축이 되므로, **시간 집계**로 독립성을 확보한다(한 구간에 웃은 순간과 화난 순간이 섞이면 P·N 둘 다 상승).

```
[프레임 0.5초]
  pos_t = happy_t
  neg_t = sad_t + 1.5·angry_t (+ disgust_t)        # ANGRY_WEIGHT=1.5
  게이트: 얼굴 신뢰도 OK 그리고 부정이 ≥3초 지속될 때만 neg 인정 (순간 오탐 배제)

[구간 집계: 통화 / 오전·오후 / 하루]   ※ duration 가중
  P (긍정)    = 100 · Σ(pos_t · dur) / Σ dur
  N (스트레스) = 100 · Σ(neg_gated · dur) / Σ dur
              (+ 고N이 오래 지속되면 소폭 누적 보너스 — 피로 개념)

[파생]
  마음균형 = P − N
  정서활력 = P + N
  잔잔(calm) = P·N 둘 다 낮음 → 좋은 신호(소진 아님)

[표시]
  지금값 = EMA(최근 가중) → 오브에 반영
  리포트 = 구간 평균 + 추이 → 오전/오후/퇴근

[기준선] 하이브리드: 처음엔 절대식, 며칠 데이터 쌓이면 "평소 대비"(개인 기준선)로 개인화
[안전장치] 불확실성 고지 · 단정 금지 · 무표정(flatAffect)을 N에 넣지 않음
```

- **calm 처리:** neutral/calm은 긍정에 억지로 넣지 않는다. P·N 둘 다 낮음 = "잔잔/안정"(좋은 상태)으로 자연 표현.
- **N 구성:** "지속된 부정"만. 순간 욱함이 아니라 *지속된 부담*을 잰다. (감정 기복/변동성, 억압/무표정은 N에서 제외 — §15 참고)

## 5. 감정 오브 (시각 설계)

오브는 사용자 상태를 **비언어로** 비추는 중심 화면. 비주얼 컴패니언으로 합의:

### 형태/렌더
- **A(리퀴드 글래스) + B(오로라) 혼합:** 유리 구의 가장자리는 또렷(blur 0), 안쪽에서 오로라 색이 천천히 흐름.
- **렌더 강도 = "또렷(crisp)":** 블러 최소(~2px), 채도↑, 작고 선명한 하이라이트. (이전 "뿌연" 느낌 제거)
- 전체가 은은하게 숨 쉼.

### 성장 (투명 → 자기 색)
데이터가 쌓일수록 투명한 유리가 **자기만의 색**으로 차오른다. (기존 `orbStages` 5단계 재사용)
- empty(아직 당신을 모릅니다) → awakening → forming → settled → living(당신과 함께 살아갑니다)
- 투명도/색 농도 = 누적 데이터량.

### 색 (2D 감정 색공간)
- 색은 2축 평면 **마음균형(가로) × 정서활력(세로)**의 한 점 → 연속적으로 수많은 색조.
  - 우상(긍정·활발)=밝은 금빛 · 좌상(부정·활발)=붉은 코랄 · 좌하(부정·조용)=짙은 청남 · 우하/하(긍정·조용)=차분한 청록
- 감정별 기준색(부드럽게, 비자극): 기쁨=따뜻한 금빛 · 평온=청록 · 슬픔=고요한 푸른빛 · **화남=따뜻한 코랄(공격적 빨강 아님)**
- **색 혼합 = 부드러운 2색 그라데이션**(상위 2감정), **최대 2색까지만** 섞어 항상 깔끔. 평균 단일색(탁해짐)·마블(산만) 회피.
- **누적 "내 색"** 베이스 + 당일 색 + 강도 → 다채로움.

### 반응 속도
- **색(hue) = 천천히 쌓인 "감정 정체성"**(며칠 단위, 차분).
- **강한 감정일 땐 잠깐 그 색이 번졌다 가라앉음.**
- **지금 상태는 주로 움직임·밝기**로(아래 3채널).

### 3채널 직관 표현 (범례 없이 읽히게)
색만으론 직관적이지 않아 3채널 중복부호화(접근성·색맹 안전):

1. **움직임·숨결 (본능 채널, 주신호):**
   - 평온 = 느리고 깊은 숨 / 기쁨 = 가볍게 떠오름+반짝임 / 슬픔 = 얕게 가라앉음 / 화남 = 빠르게 들이쉬고 참았다 천천히 (떨림·번개·색점멸 금지, 절제)
2. **한 줄 텍스트 (의미 확정 채널, 토스 톤):** 주어는 "마음/오브", 비단정. (§9)
3. **색 + 명도 (보조·색맹 백업):** §5 색 + 명도 차(기쁨 밝음→슬픔 어두움)로 흑백에서도 구분.

## 6. 피드백 모델 (교수 "재검토" 반영)

per-call 즉시 카드는 폐기. 다음 4층:

1. **오브 (상시·수동):** P/N → 색·숨결. PiP 오버레이로 항상 곁에.
2. **오전·오후 체크인 (30초):** 지금 P/N 한 줄 + (선택) **self-report 1탭 보정**("맞아요 / 지금은 좀 달라요" — 카메라 오차를 본인이 교정).
3. **퇴근 통합 리포트:** 오늘 P/N + 추이 그래프 + 힘들었던 시간대 + (스트레스 높으면) 설문 기반 **해소법 제안 1개**.
4. **안전판 넛지:** N이 오래 높게 지속되면 부드러운 넛지 — **빈도 상한** + **사용자 토글**(켜고/끄고 빈도 조절). 강제 없음, 닫기/나중에 쉬움.

## 7. 개인화 & 온보딩

- **로컬 프로필** ("회원가입 느낌"의 온보딩, 데이터는 기기에만 / 서버·계정 없음).
- 온보딩 설문 = **"나만의 스트레스 해소법"**: 좋아하는 음료/간식, 1분 회복 활동, 호흡/마음챙김, 위로 문구·이미지, (설정) 방해금지 시간·빈도 상한. **음악 항목은 제외.**
- 해소법 제안은 설문 + 내부 감정으로 맞춤(화남→호흡, 슬픔→위로 문구 등).

## 8. 오버레이 (오브 상시 표시)

- **Document Picture-in-Picture:** 작은 오브 창을 항상 최상단에 띄움. 메인 앱을 최소화해도 오브는 남는다. 웹앱 유지·설치 불필요.
- 제약: Chrome/Edge, 브라우저는 백그라운드로 켜져 있어야 함(최소화 OK, 완전 종료 X), 시작은 사용자 클릭 1회.
- **후순위:** "브라우저도 끄고 완전 독립"을 원하면 Electron/Tauri 데스크톱 앱(future).

## 9. 카피 가이드 (토스 톤)

짧고, 다정하고, 부담 없이. 주어는 "마음/오브", 비단정(`~해요/~할게요/~할까요?`).

**오브 한 줄 (4감정):**
- 평온: `마음이 잔잔해요 🌿`
- 기쁨: `오늘 기분, 좋아 보여요 ☀️`
- 슬픔: `오늘 좀 무거웠죠. 천천히 가요`
- 화남: `마음에 힘이 들어갔네요. 잠깐 숨 돌릴까요?`
- ※ 강도에 따라 길이 가변(약함 → 더 짧게).

**리포트/상태 예시:**
- 대기: `마음이 잔잔해요 🌿`
- 종료: `기록했어요 ✓ / 방해 안 할게요. 이따 한눈에 보여드릴게요`
- 퇴근 리포트: `오늘도 고생했어요` / `오후에 좀 바빴죠. 좋아하는 커피 한 잔 하고 가요 ☕` · 버튼 `좋아요` / `괜찮아요`

## 10. 데모 시나리오 (발표용 5컷)

상시 배경이지만 데모는 **전화 수신**을 트리거로 콜센터 맥락을 연출. ("전화가 오면 그때부터")

1. **근무 중·대기** — 잔잔한 청록 오브
2. **📞 전화 수신 (트리거)** — 착신 화면, [받기]/[거절]
3. **통화 중** — 오브가 코랄로 라이브 반응 (화면엔 안 띄우고 PiP 오브로만 = 비침습)
4. **통화 종료** — 즉시 카드 X, "기록했어요 ✓"
5. **퇴근 통합 리포트** — 긍정/스트레스 게이지 + 추이(오후↑) + 해소법 제안 카드

## 11. 데이터 모델 / 아키텍처

- **플랫폼:** Next.js 16 + Tailwind v4 웹앱(PWA). `face-api.js`. **IndexedDB(Dexie)** = 감정 기록, **localStorage** = 프로필/설문/설정. 모든 추론은 온디바이스(브라우저).
- **저장 데이터:** 감정 기록(시간대/통화 세션 단위), P/N 산출값, 프로필/설문, 설정. 원시 시계열 보존은 최소화(가능하면 트리거 계산 후 폐기 옵션).
- **통화 세션:** 상시 배경 + "통화 중" 구간 표시(callId·시작·종료, 식별정보 없음) → 리포트에서 "통화 후 스트레스↑" 분석.
- **토대 브랜치:** main 기준 신규 구현. 기존 `feature/living-orb-and-tone`의 `orbStages`(5단계), `orbAxes`(축 매핑 개념), `weeklyEmotion`(집계) 로직은 참고·재사용하되, 오브 렌더는 "또렷" 기준으로 재구성.

## 12. 프라이버시 · 윤리 (red-team 반영)

- **포지셔닝:** "직장 감정 모니터링"이 아니라 **"본인 주도 셀프 회고/웰빙"**. 트리거는 본인 사용, 평가·인사와 무관.
- **EU AI Act Art.5(1)(f):** 직장 감정인식은 금지 관행. README/디펜스에 적용 분석 1단락 — (a)노동자 본인이 설치·통제 (b)고용 의사결정에 일절 미사용 (c)데이터가 기기를 떠나지 않음 을 리스크 완화 설계로 명시(법적 면제 주장 아님).
- **감시 불가능성 설계:** 서버 전송 경로 없음, 관리자 뷰 없음, export/공유 버튼 영구 미구현, 원클릭 전체 삭제, (옵션) 앱 잠금/위장 모드.
- **wellness washing 한계 정직 고지:** "이 앱은 노동조건을 바꾸지 못한다. 회복은 당신 책임이 아니라 권리다." + 감정노동자 보호제도/상담 연결 정보 1줄.
- **타당성 정직:** 표정→감정은 자주 틀림을 고지, posed-anger 데모의 한계 인정, self-report 보정 제공.

## 13. 비목표 (Out of Scope)

서버/계정, 관리자 대시보드, 다기기 동기화, 음성/대화 내용 처리, 고객 식별정보 저장, 데스크톱 앱(현 단계), 음악 설문 항목, 임상 진단/의료기기 주장.

## 14. 구현 단계

- **P0** 정확도 보강 (disgust 합치기, angry 임계↓·스무딩·지속 게이트)
- **P1** 2축 스트레스 지수 엔진 (P/N 산출, 지속 게이트, 구간 집계, EMA, 하이브리드 기준선)
- **P2** 감정 오브 엔진 (글래스+오로라 또렷 렌더, 2D 색공간, 3채널, 5단계 성장)
- **P3** PiP 오버레이
- **P4** 온보딩 설문(로컬 프로필) + 개인화 피드백(오전/오후 체크인, 퇴근 리포트, 넛지+토글)
- **P5** 데모 시뮬 수신 흐름 (발표용 5컷)
- **P6** (후순위) HSEmotion 모델 교체
- (전역) 프라이버시/윤리 문서화(README + 디펜스 슬라이드)
