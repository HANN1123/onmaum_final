# 체크인 보정 설계와 검증

- 작성: 이정환 (⑤ 감정 및 개인 상태 분석 / ⑥ 개인 맞춤 피드백), 2026-10-22
- 대상: `features/algorithm/baseline/calibration.ts`의 `nextOffset`·`applyOffset`, 체크인 기록(`shared/storage/dayState.ts`)
- 배경: 로직 검토 보고서 F3 — 체크인 보정값(점수)이 기준선 크기에 따라 판정에 주는 영향이 크게 다르다는 지적
- 조사: 이정환(Claude Code)과 Codex가 2010년 이후 문헌을 각각 검색하고 교차 확인. 2010년 이전 문헌은 표시해 둔다

## 1. 결론

| 항목 | 결정 | 근거 |
|---|---|---|
| "맞아요" 응답 | 보정값을 **유지**한다 (이전: 0쪽으로 1점 감쇠) | 합성 시뮬레이션에서 모든 조건에서 감쇠보다 체감 일치율이 높음 (3절) |
| 보정 방식 | 점수를 더하는 지금 방식 유지 | 합성 시뮬레이션의 두 체감 모델 모두에서 가장 안정적 (3절) |
| 단계·상한 | 3점, ±15 유지 | 민감도 분석에서 가장 좋거나 비슷 (3.3절). 문헌으로 검증된 값은 아님 |
| 체크인 기록 | 응답과 함께 **그때 보여 준 판정과 근거**를 저장 | 실제 사용자 데이터로 다시 검증하기 위한 준비 (5절) |
| 비율 보정 (이전 제안 (c), 곱셈형·덧셈형) | **채택하지 않음** | 합성 모델에서 측정값보다 체감이 점수로 크게 높은 사용자를 놓침 (3.2절) |
| 개인 z-score·MAD 판정 | 지금은 채택하지 않음 | 기록 일수가 적을 때의 안정성을 확인하지 못함 (2절) |

이 검증은 **합성 사용자 시뮬레이션**과 문헌에 근거한 설계 검증이다. 실제 사용자에게서 판정이 맞는지는 5절의 방법으로 따로 검증해야 한다.

## 2. 문헌에서 가져온 원칙

문헌이 직접 보여 준 것과, 그것을 근거로 온마음에서 내린 결정을 나눠 적는다. 단계 3점·상한 ±15·하루 2회 같은 값은 문헌이 검증한 값이 아니다.

| 문헌이 보여 준 것 | 출처 | 온마음의 결정 |
|---|---|---|
| 실생활 스트레스 검출에서 개인 자신의 데이터를 기준으로 비교할 때 가장 좋았다. 개인차를 반영한 모델이 일반 모델보다 기분·스트레스 예측이 나았다 | JMIR 2023 (doi:10.2196/39995), Taylor 외 2020 (doi:10.1109/TAFFC.2017.2784832) | 개인 기준선 대비 판정 유지 |

| 평균·SD보다 중앙값·MAD가 이상값에 강하다 | Leys 외 2013 (doi:10.1016/j.jesp.2013.03.013) | 기준선을 중앙값으로 계산하는 지금 방식 유지 |
| 표정을 억누르면 표현은 줄지만 주관적 정서는 줄지 않는다. 얼굴과 정서의 대응은 사람·상황마다 다르다 | Gross·Levenson 1993 (2010년 이전), Roberts 외 2008 (2010년 이전, doi:10.1016/j.ijpsycho.2008.06.003), Barrett 외 2019 (doi:10.1177/1529100619832930) | 보정이 "측정값은 낮은데 실제로 힘든" 사용자를 "높음"까지 올릴 수 있어야 한다고 보고, 시뮬레이션에 점수 체감 모델을 넣었다 |
| 경험 표집을 반복하면 응답 시간·개인 내 분산·정서가 변하고 익숙해짐이 나타난다 | Eisele 외 2023 (doi:10.1037/pas0001177) | 응답 한 번에 크게 바꾸지 않는다 (작은 단계, 상한) |
| 하루 끝에 회상한 부정 정서가 순간 평가 평균보다 강하다 | Neubauer 외 2020 (doi:10.1037/pspp0000248) | 같은 이유로 응답을 작은 단계로 누적 |
| 첫 응답이 높게 나오는 편향 보고와, 일관되지 않다는 반론이 있다 | Shrout 외 2018 (doi:10.1073/pnas.1712277115), Cerino 외 2022 (doi:10.1037/pas0001108) | 첫 응답을 따로 할인하지 않는다 |
| 적은 라벨로 개인화할 때 공통 정보를 공유하거나 라벨 요청 시점을 고르면 효율이 오른다 | Taylor 외 2020, Tazarv 외 2023 (doi:10.1145/3580252.3586979) | 상한을 둔다. 체크인 시점 선택은 후속 과제 |
| 생리 신호 기반 개인 임계값은 신호·맥락·지속시간과 함께 검증되었다 | Schwerdtfeger 외 2025 (doi:10.2196/69582), Bögemann 외 2025 (doi:10.3758/s13428-025-02870-5) | 다른 신호의 임계값을 옮겨 오지 않고 5절의 방법으로 직접 검증 |

## 3. 시뮬레이션 검증

### 3.1 방법

- **CI 검증:** `tests/algorithm/baseline/calibrationSimulation.test.ts`가 실제 판정 함수(`classifyStress`)와 보정 함수(`applyOffset`, `nextOffset`)를 그대로 써서 3.4절 조건을 확인한다.
- **표의 수치:** `docs/architecture/calibration/simulate.mjs`로 다시 만들 수 있다(`node docs/architecture/calibration/simulate.mjs`). 같은 판정 상수를 옮겨 여러 방식을 비교한다.

설정:

- 사용자: 평소 부정 정서 B ∈ {8, 15, 25, 40, 60} × 측정과 체감의 어긋남 ∈ {−30%, −15%, 0, +15%, +30%} × 반복 20 = **체감 모델마다 500명**
- 하루 측정값: B × 로그정규 잡음(σ = 0.3), 30일, 하루 체크인 2회
- 응답: 보여 준 판정이 체감보다 낮으면 "더 힘들었어요", 높으면 "괜찮았어요", 같으면 "맞아요". 미응답 40%, 무작위 응답 15%
- 체감 판정은 CI 테스트와 같이 체감값 자체에 같은 판정 규칙(바닥 조건 포함)을 적용한다
- 체감 모델 두 가지 (실제 사용자가 어느 쪽인지 모른다)
  - 비율 모델: 체감 = 측정값 × (1 + 어긋남)
  - 점수 모델: 체감 = 측정값 + 어긋남 × 50점. 측정값이 낮아도 체감이 높은 경우를 포함
- 지표: 15~30일차에 보여 준 판정이 체감 판정과 같은 비율, 두 단계 이상 어긋난 비율, 1주차 일치율

**이 설계의 가정과 한계** (결과는 이 가정 안에서만 성립한다)

- 체감 판정도 같은 `classifyStress`로 만든다. 즉 "사용자는 우리와 같은 경계로 상태를 나눈다"고 가정한다.
- 사용자별 어긋남은 30일 동안 일정하다. 실제로는 바뀔 수 있다.
- 미응답과 무작위 응답은 상태와 무관하다. 실제로는 힘들 때 응답을 덜 할 수 있다.
- 점수 모델의 최대 어긋남(±15점)이 보정 상한(±15)과 같다. 그래서 점수 모델이 현재 규칙에 유리하다. ±45% 조건(3.3절)으로 일부 확인했다.
- 기준선을 알고 있다고 두었다. 실제로는 기록이 쌓이며 바뀐다.

### 3.2 방식 비교

미응답 40%, 무작위 응답 15%:

비율 보정은 두 형태를 모두 비교했다. 곱셈형은 (N/B) × (1 + c), 덧셈형은 N/B + c이며 c = 보정값/50(±0.3)이다.

| 방식 | 비율 모델 일치 | 점수 모델 일치 | 두 단계↑ 어긋남 (최대) |
|---|---|---|---|
| 보정 없음 | 63.9% | 47.8% | 11.6% |
| 이전 규칙 (점수, 맞아요 감쇠) | 79.3% | 77.8% | 1.9% |
| **현재 규칙 (점수, 맞아요 유지)** | **85.5%** | **90.6%** | **0.5%** |
| 곱셈형 비율 보정 + 감쇠 | 80.5% | 68.4% | 8.4% |
| 곱셈형 비율 보정 + 유지 | 90.9% | 74.6% | 8.3% |
| 덧셈형 비율 보정 + 유지 | 87.6% | 75.0% | 8.4% |
| 곱셈형 비율 보정 + 유지 + 보정값에 바닥 조건 | 92.2% | 75.5% | 6.1% |
| 비율·점수 혼합 + 유지 | 87.3% | 86.2% | 3.1% |

미응답 70%, 무작위 응답 30%에서도 순서가 같았다. 현재 규칙은 비율 80.9%·점수 83.4%, 이전 규칙은 75.9%·72.8%였다.

- 비율 보정은 곱셈형·덧셈형 모두 비율 모델에서는 좋지만, 점수 모델에서 두 단계 이상 어긋남이 8% 안팎으로 늘었다. 보정 범위가 ±30%로 좁고 "20점 이상" 조건이 원래 측정값에 걸려서, 이 합성 모델에서 측정값보다 체감이 크게 높은 사용자를 "높음"으로 올리지 못했다. 표정 억제 문헌(2절)을 고려하면 실제 사용자에게도 이런 경우가 있을 수 있지만, 그 비율은 실제 데이터로 확인해야 한다.
- 이전 분석에서 걱정한 "기준선이 작은 사람은 보정 효과가 크다"는 사람 사이의 차이다. 보정값은 한 사람 안에서 그 사람의 기준선에 맞춰 쌓이므로 이 모델에서는 일치율에 큰 문제가 되지 않았다.

### 3.3 단계·상한 민감도 (현재 규칙, 두 모델 중 낮은 쪽)

| 단계 / 상한 | 어긋남 ±30% | 어긋남 ±45% | 두 단계↑ 최대 | 1주차 (±30%) |
|---|---|---|---|---|
| 2 / 10 | 82.9% | 69.8% | 7.5% | 63.0% |
| **3 / 15 (현재)** | **85.5%** | **83.3%** | **0.7%** | **68.5%** |
| 3 / 21 | 85.9% | 85.4% | 0.5% | 68.5% |
| 5 / 15 | 81.8% | 81.3% | 0.9% | 73.5% |
| 5 / 25 | 82.1% | 84.2% | 0.9% | 73.4% |

- 단계를 5로 키우면 1주차 일치율은 오르지만(+5%p) 이후 일치율이 떨어진다. 무작위 응답에 크게 흔들리기 때문이다.
- 상한 21은 어긋남이 큰 사용자에서 조금 낫지만 차이가 작다. 시뮬레이션 가정에 맞춰 값을 바꾸지 않고 현재 값을 유지한다. 실제 데이터에서 보정값이 상한에 자주 머물면 다시 본다.

### 3.4 CI에서 고정한 검증 조건

`calibrationSimulation.test.ts`는 두 체감 모델 각각에서 다음을 확인한다.

1. 현재 규칙이 보정 없음보다 일치율이 10%p 이상 높다
2. 현재 규칙이 이전 규칙(감쇠)보다 일치율이 높다
3. 15~30일차 일치율 80% 이상, 두 단계 이상 어긋남 2% 미만

이전 규칙으로 돌리면 2·3번이 실패하는 것을 확인했다. 이 조건은 규칙이 바뀌어 성능이 떨어지는 것을 막는 회귀 검사이며, 실제 정확도를 보증하지 않는다.

## 5. 실제 사용자 검증 방법 (다음 단계)

저장된 `context`가 있으면 무엇을 할 수 있고 무엇을 할 수 없는지 구분한다.

**`context`만으로 할 수 있는 것**

- 보정값이 상한에 머무는 비율, "더 힘들었어요"·"괜찮았어요"가 같은 방향으로 이어지는 횟수를 본다.
- 응답 방향과 보정 방향이 맞았는지(예: "더 힘들었어요" 다음 판정이 올라갔는지)를 본다.
- 응답률은 볼 수 없다. `context`는 응답한 체크인에만 저장되므로 분모인 "체크인을 보여 준 횟수"가 없다. 응답률과 미응답 편향을 보려면 체크인 카드를 보여 준 시각과 닫은 방식(응답·닫기·무시)을 따로 기록해야 한다.

**`context`만으로 할 수 없는 것**

- 기록된 응답을 다른 규칙에 재생해 일치율을 비교하는 것. "더 힘들었어요"는 그때 보여 준 판정에 대한 **상대적인** 답이라서, 예를 들어 "평소와 비슷"에 대한 "더 힘들었어요"가 "높음"인지 "매우 높음"인지 알 수 없다. 또 다른 규칙이었다면 다른 판정을 보여 줬고 응답도 달랐을 것이다.

**그래서 필요한 것: 독립적인 상태 라벨**

1. 일부 체크인(예: 5회 중 1회, 무작위)은 판정을 보여 주기 **전에** 현재 상태를 네 단계("가벼움 / 보통 / 힘듦 / 많이 힘듦")로 묻는다. 판정이 높을 때만 묻지 않도록 무작위로 고른다.
2. 이 라벨이 쌓이면, 시간 순서대로 각 시점까지의 응답으로만 보정값을 갱신하고 그다음 독립 라벨과 비교한다. 이전 규칙·현재 규칙·비율 보정·z-score 판정을 같은 라벨로 비교할 수 있다.
3. 보고할 지표: 전체 일치율, 개인별 오탐·누락, 두 단계 이상 어긋남, 보정값이 상한에 머무는 비율, 하루 알림 수, 응답률.
4. 다시 볼 매개변수: 단계(3), 상한(±15), 장기 무응답 시 시간 감쇠 여부(지금은 없음), 판정 경계(0.8 / 1.25 / 1.6), 바닥 조건(20).

1번과 체크인 노출 기록은 화면 변경이 필요하므로 김우빈과 함께 정한다.

## 6. 한계

- 시뮬레이션 결과는 3.1절의 가정 안에서만 성립한다. 두 체감 모델과 두 응답 조건에서 방식 사이의 순서가 같았다는 것이 근거이며, 표의 일치율이 실제 사용자 일치율을 뜻하지 않는다.
- 문헌의 상당수는 생리 신호·자기보고 연구다. 표정 기반 지표에 그대로 옮길 수 있는지는 검증 대상이다.
