# 체크인 보정 설계와 검증

- 작성: 이정환 (⑤ 감정 및 개인 상태 분석 / ⑥ 개인 맞춤 피드백), 2026-10-22
- 대상: `features/algorithm/baseline/calibration.ts`의 `nextOffset`·`applyOffset`, 체크인 기록(`shared/storage/dayState.ts`)
- 배경: 로직 검토 보고서 F3 — 체크인 보정값(점수)이 기준선 크기에 따라 판정에 주는 영향이 크게 다르다는 지적
- 조사: 이정환(Claude Code)과 Codex가 2010년 이후 문헌을 각각 검색하고 교차 확인

## 1. 결론

| 항목 | 결정 | 근거 |
|---|---|---|
| "맞아요" 응답 | 보정값을 **유지**한다 (이전: 0쪽으로 1점 감쇠) | 시뮬레이션에서 모든 조건에서 감쇠보다 체감 일치율이 높음 (3절) |
| 보정 방식 | 점수를 더하는 지금 방식 유지 | 사용자 체감이 비율·점수 어느 쪽으로 어긋나든 가장 안정적 (3절) |
| 단계·상한 | 3점, ±15 유지 | 민감도 분석에서 가장 좋거나 비슷 (3.3절) |
| 체크인 기록 | 응답과 함께 **그때 보여 준 판정과 근거**를 저장 | 실제 사용자 응답으로 규칙을 다시 검증하기 위해 (5절) |
| 비율 보정 (이전 제안 (c)) | **채택하지 않음** | 표정을 억누르는 사용자에게서 크게 어긋남 (3.2절) |
| 개인 z-score·MAD 판정 | 채택하지 않음 (지금은) | 기록 일수가 적어 개인 변동폭 추정이 불안정 (2절) |

이 검증은 **합성 사용자 시뮬레이션**과 문헌에 근거한다. 실제 사용자 데이터로 하는 검증은 5절의 방법으로 이어서 한다.

## 2. 문헌에서 가져온 원칙

| 원칙 | 문헌 | 온마음 적용 |
|---|---|---|
| 개인 자신의 기록을 기준으로 판정 | 실생활 스트레스 검출에서 개인 데이터 기준 비교가 가장 좋았음 (JMIR 2023, doi:10.2196/39995). 개인별 모델이 일반 모델보다 기분·스트레스 예측이 나음 (Taylor 외 2020, doi:10.1109/TAFFC.2017.2784832) | 개인 기준선(중앙값) 대비 판정 유지 |
| 개인 표준화는 관측이 충분할 때만 | 개인 내 표준화는 집중 종단 연구에서 흔하지만 개인 간 평균 차이를 지움 (Moeller 2015, doi:10.3389/fpsyg.2015.01389). 개인별 SD를 안정적으로 추정하려면 많은 관측이 필요 (Wang 외 2019, doi:10.1080/00273171.2018.1532280) | 3~13일 기록으로는 SD·MAD가 불안정하므로 z-score로 바꾸지 않음 |
| 평균·SD보다 중앙값·MAD가 이상값에 강함 | Leys 외 2013, doi:10.1016/j.jesp.2013.03.013 | 기준선을 중앙값으로 계산하는 지금 방식 유지 |
| 표정은 억눌러도 느낌은 그대로 | 표정 억제는 표현을 줄이지만 주관적 정서는 줄이지 않음 (Gross·Levenson 1993; Roberts 외 2008, doi:10.1016/j.ijpsycho.2008.06.003). 얼굴과 정서의 대응은 사람마다 다름 (Barrett 외 2019, doi:10.1177/1529100619832930) | 보정이 "측정값은 낮은데 실제로 힘든" 사용자를 "높음"까지 올릴 수 있어야 함 → 비율 보정·원값 바닥 조건을 채택하지 않은 이유 |
| 반복 자기보고는 응답을 바꾼다 | 경험 표집 반복 측정에서 응답 시간·개인 내 분산·정서가 변하고 익숙해짐이 나타남 (Eisele 외 2023, doi:10.1037/pas0001177) | 체크인을 하루 2회로 유지하고, 응답 한 번에 크게 바꾸지 않음 (단계 3점, 상한) |
| 회상 응답은 순간 응답과 다르다 | 하루 끝에 회상한 부정 정서가 순간 평가 평균보다 강함 (Neubauer 외 2020, doi:10.1037/pspp0000248) | 응답 한 번을 그대로 믿지 않고 작은 단계로 누적 |
| 첫 응답 할인 규칙은 근거가 엇갈림 | 초기 응답이 높게 나오는 편향 보고 (Shrout 외 2018, doi:10.1073/pnas.1712277115), 일관되지 않다는 반론 (Cerino 외 2022, doi:10.1037/pas0001108) | 첫 응답을 따로 할인하지 않음 |
| 적은 라벨로 과보정하지 않기 | 공통 정보를 공유하며 개인차를 반영하는 방식 (Taylor 외 2020). 맥락을 고려한 라벨 요청으로 질의 수를 크게 줄임 (Tazarv 외 2023, doi:10.1145/3580252.3586979) | 보정값 상한 ±15 유지. 체크인 시점 선택은 후속 과제 |
| 개인 임계값은 함께 검증해야 한다 | 개인 HRV 예측 대비 0.5 SD 조건으로 개입 (Schwerdtfeger 외 2025, doi:10.2196/69582). EMA·생리 지표 개인 임계값 시스템을 215명에서 평가, 하루 1.61회 개입·EMA 응답률 43% (Bögemann 외 2025, doi:10.3758/s13428-025-02870-5) | 다른 신호의 임계값을 옮겨 오지 않고, 5절의 방법으로 직접 검증 |

Taylor 외, Wang 외, Leys 외, Eisele 외, Neubauer 외, Shrout 외, Cerino 외, Tazarv 외, Schwerdtfeger 외, Bögemann 외는 Codex가 확인한 서지다. 인용 전에 원문을 다시 확인한다.

## 3. 시뮬레이션 검증

### 3.1 방법

실제 판정 함수(`classifyStress`)와 보정 함수(`applyOffset`, `nextOffset`)를 그대로 쓰는 합성 사용자 시뮬레이션이다. 코드는 `tests/algorithm/baseline/calibrationSimulation.test.ts`에 있고 CI에서 매번 돈다. 아래 표의 수치는 같은 모델로 여러 방식을 비교한 탐색용 스크립트의 결과이며(난수 시드가 달라 CI 테스트 값과 소수점이 조금 다를 수 있다), CI 테스트는 3.4절의 조건만 확인한다.

- 사용자 2,500명분: 평소 부정 정서 B ∈ {8, 15, 25, 40, 60} × 측정과 체감의 어긋남 ∈ {−30%, −15%, 0, +15%, +30%} × 반복 20
- 하루 측정값: B × 로그정규 잡음(σ = 0.3), 30일, 하루 체크인 2회
- 응답: 보여 준 판정이 체감보다 낮으면 "더 힘들었어요", 높으면 "괜찮았어요", 같으면 "맞아요". 40% 미응답, 15% 무작위 응답
- **체감 모델 두 가지** (실제 사용자가 어느 쪽인지 모르므로 둘 다 본다)
  - 비율 모델: 체감 = 측정값 × (1 + 어긋남)
  - 점수 모델: 체감 = 측정값 + 어긋남 × 50점. 표정을 억눌러 측정값이 낮은데 실제로 힘든 경우를 포함
- 지표: 15~30일차에 보여 준 판정이 체감 판정과 같은 비율, 두 단계 이상 어긋난 비율, 1주차 일치율

### 3.2 방식 비교 (미응답 40%, 잡음 15%)

| 방식 | 비율 모델 일치 | 점수 모델 일치 | 두 단계↑ 어긋남 (최대) |
|---|---|---|---|
| 보정 없음 | 65.8% | 47.8% | 11.6% |
| 이전 규칙 (점수, 맞아요 감쇠) | 79.5% | 77.8% | 1.9% |
| **현재 규칙 (점수, 맞아요 유지)** | **85.2%** | **90.6%** | **0.6%** |
| 비율 보정 + 감쇠 | 81.6% | 68.4% | 8.4% |
| 비율 보정 + 유지 | 92.5% | 74.6% | 8.3% |
| 비율 보정 + 유지 + 보정값에 바닥 조건 | 91.0% | 75.5% | 6.1% |
| 비율과 점수 혼합 + 유지 | 86.7% | 86.2% | 3.1% |

응답이 더 나쁜 조건(미응답 70%, 잡음 30%)에서도 순서가 같았다. 이때 현재 규칙은 비율 80.6%·점수 83.4%, 이전 규칙은 76.3%·72.8%였다.

- 비율 보정은 체감이 비율로 어긋날 때 가장 좋지만, 점수로 어긋나는 사용자(표정은 적은데 힘든 사람)에서 두 단계 이상 어긋남이 8%까지 늘었다. 상한이 ±30%로 좁고 "20점 이상" 조건이 원래 측정값에 걸리기 때문이다. 감정노동자의 표정 억제 문헌을 고려하면 이 경우를 놓치는 것이 더 위험하다.
- 이전 분석에서 걱정한 "기준선이 작은 사람은 보정 효과가 크다"는 사람 사이의 차이다. 보정값은 한 사람 안에서 그 사람의 기준선에 맞춰 쌓이므로 실제 일치율에는 큰 문제가 되지 않았다.

### 3.3 단계·상한 민감도 (현재 규칙, 두 모델 중 낮은 쪽)

| 단계 / 상한 | 어긋남 ±30% | 어긋남 ±45% | 두 단계↑ 최대 |
|---|---|---|---|
| 2 / 10 | 82.9% | 69.8% | 7.5% |
| **3 / 15 (현재)** | **85.5%** | **83.3%** | **0.7%** |
| 3 / 21 | 85.9% | 85.4% | 0.6% |
| 5 / 15 | 81.8% | 81.3% | 0.9% |
| 5 / 25 | 82.1% | 84.2% | 0.9% |

- 단계를 5로 키우면 1주차 일치율은 오르지만(+5%p 안팎) 이후 일치율이 떨어진다. 잡음 응답에 크게 흔들리기 때문이다.
- 상한 21은 어긋남이 큰 사용자에서 조금 낫지만 차이가 작다. 시뮬레이션 가정에 맞춰 값을 바꾸지 않고 현재 값을 유지한다. 실제 데이터(5절)에서 보정값이 상한에 자주 닿으면 다시 본다.

### 3.4 CI에서 고정한 검증 조건

`calibrationSimulation.test.ts`는 두 체감 모델 각각에서 다음을 확인한다.

1. 현재 규칙이 보정 없음보다 일치율이 10%p 이상 높다
2. 현재 규칙이 이전 규칙(감쇠)보다 일치율이 높다
3. 15~30일차 일치율 80% 이상, 두 단계 이상 어긋남 2% 미만

이전 규칙으로 돌리면 2·3번이 실패하는 것을 확인했다.

## 5. 실제 사용자 검증 방법 (다음 단계)

시뮬레이션은 사용자 응답 방식을 가정한다. 실제 검증은 저장된 `context`로 한다.

1. **시간 순서 재생 평가:** 기록된 체크인을 시간순으로 재생하면서, 각 시점까지의 응답으로만 보정값을 갱신하고 다음 응답과 비교한다. 같은 기록으로 이전 규칙·현재 규칙·비율 보정을 비교할 수 있다.
2. **판정을 보기 전에 묻는 체크인 일부 섞기:** 지금 체크인은 판정 문구를 본 뒤 답하므로 문구에 끌릴 수 있다. 일부 체크인(예: 5회 중 1회, 무작위)은 판정을 보여 주기 전에 상태를 묻고, 판정이 높을 때만 묻지 않도록 한다. 화면 변경이 필요하므로 김우빈과 함께 정한다.
3. **보고할 지표:** 전체 일치율뿐 아니라 개인별 오탐·누락, 두 단계 이상 어긋남, 보정값이 상한에 머무는 비율, 하루 알림 수, 응답률.
4. **다시 볼 매개변수:** 단계(3), 상한(±15), 장기 무응답 시 시간 감쇠 여부(지금은 없음), 비율 판정 경계(0.8 / 1.25 / 1.6).

## 6. 한계

- 시뮬레이션 결과는 가정한 응답 방식(체감 모델 두 가지, 미응답·잡음 비율)에 따라 달라진다. 두 모델과 두 응답 조건에서 순서가 같았다는 것이 근거이며, 실제 일치율 수치를 뜻하지 않는다.
- 기준선은 시뮬레이션에서 알고 있다고 두었다. 실제로는 기록이 쌓이며 바뀐다.
- 문헌의 상당수는 생리 신호·자기보고 연구다. 표정 기반 지표에 그대로 옮길 수 있는지는 검증 대상이다.
