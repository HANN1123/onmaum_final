# rPPG 심박 추정 튜닝: 공개 데이터셋 오프라인 평가

작성 2026-11-04, 갱신 2026-11-05. 대상 브랜치 `feat/rppg-tuning-shared-face`(origin/main 기반, 얼굴 상자 공유와 ME-rPPG 튜닝을 한 PR로 정리).

## 결론

- 모델 출력(맥박 파형)을 심박수로 바꾸는 단계를 고쳤다. 대역 통과, 직전 값 추적, 얼굴 흔들림 주파수 제거, 움직임 게이트를 넣었다(`features/rppg/lib/hrEstimator.ts`).
- 측정 화면 엔진(`useMeRppg`)과 실험실 튜닝 추정은 ME-rPPG 하나에 이 추정기를 쓴다. FacePhys는 평가했지만 앱에는 넣지 않았다. 단독으로 모든 조건에서 ME-rPPG보다 나빴고, 결합해도 이득이 작고 어두운 조건에서는 오히려 나빴다. 아래 FacePhys 수치는 이 제외 결정의 근거다.
- 공개 데이터셋 60개 영상에서 평균 오차가 2.73 → 2.26 BPM으로 줄었다. 어두운 조건(합성)에서는 3.65 → 2.67 BPM이었다.
- 고개를 계속 흔드는 조건(합성)에서는 두 모델 모두 맥박 대신 끄덕임 주기(66 BPM)를 냈고, SNR 게이트로는 걸러지지 않았다. 움직임 게이트(얼굴 너비의 2% 이상 흔들림)가 이 구간을 전부 숨긴다. 틀린 숫자 대신 "움직임 감지"를 보여 준다.
- 한계: 실제 말하기·움직임에 정답 심박이 있는 데이터가 없다. 움직임 기준값(2%)은 합성 시험으로 정한 잠정값이다. 실험실의 "파형 저장"으로 실제 기록을 모아 다시 정해야 한다.

## 데이터

- **MCD-rPPG**(Egorov et al., ACM MM 2025, [Hugging Face](https://huggingface.co/datasets/kyegorov/mcd_rppg), CC BY 4.0)
  - 600명 중 30명을 고르게 뽑았다.
  - 정면 웹캠(FullHDwebcam, 640×480, 약 30fps) 영상을 썼다. 사람마다 휴식 1편과 운동 직후(스쿼트 15회) 1편, 각 3분이다.
  - 정답은 영상 프레임에 동기화된 접촉식 PPG(`ppg_sync`)다.
- 영상·얼굴 이미지는 저장소에 넣지 않았다. 평가에 쓴 숫자 결과만 이 문서에 남긴다.

## 방법

1. **앱과 같은 경로로 파형 만들기**: 헤드리스 Chrome에서 앱과 같은 처리를 프레임마다 돌렸다.
   - BlazeFace(VIDEO 모드, 임계값 0.5)로 얼굴을 찾고, 칼만으로 상자를 다듬는다.
   - 상자를 높이 1.2배로 늘리고 위로 20% 올린 뒤, 36×36으로 줄여 ME-rPPG와 FacePhys에 넣었다.
   - 프레임 시각은 데이터셋 메타의 실제 촬영 시각을 썼다. 영상은 320×240으로 디코딩했다.
2. **합성 조건**: 정면 영상 24편(12명 × 휴식·운동 직후)의 앞 2분에 아래 변형을 넣었다.
   - **어두움**: 밝기를 40%로 낮추고 센서 잡음(σ 3)을 더했다.
   - **흔들림**: 좌우 흔들림(0.25Hz, ±20px), 끄덕임(1.1Hz = 66 BPM, ±4px), 기울기(±4°), 앞뒤 거리(±5%)를 넣었다.
3. **비교 방법**: 30초부터 2초 간격으로 추정했다. 정답은 같은 시각에서 끝나는 10초 PPG의 스펙트럼 피크다.
   - 평가 지점은 휴식·운동 조건 4,322개, 합성 조건마다 998개다.
   - 창 길이(10·15·20·30초), 대역 통과 유무, 결합 방식, 추적 폭, 고조파 가중, 움직임 마스크 기준을 모두 조합해 비교했다.

## 결과 (평균 절대 오차, BPM)

| 조건 | 현재 앱(ME, 10초) | 튜닝(ME, 대역 통과+추적) | FacePhys 단독 | 결합(ME+FP 정규화 합, 튜닝) |
|---|---|---|---|---|
| 휴식·운동 직후 60편 | 2.73 | **2.26** | 3.72 | 2.17 |
| 어두움(합성) 24편 | 3.65 | **2.67** | 4.51 | 3.05 |
| 흔들림(합성) 24편 | 15.43 | 10.36 (마스크 포함) | 16.73 | 9.83 (마스크 포함) |

- **10 BPM 넘게 틀린 비율**: 휴식·운동 조건에서 7.3% → 6.0%, 어두움에서 10.1% → 7.8%로 줄었다.
- **SNR 0dB 게이트를 통과한 값만 보면**:
  - 휴식·운동 조건: 표시 비율이 69% → 75%로 늘었다. 그 값의 오차는 1.03 → 1.11 BPM이고, 5 BPM 안에 든 비율은 98.7% → 98.2%로 비슷하다.
  - 어두움 조건: 표시 비율 67%, 오차 1.27 BPM이다.
- **영상별 비교**(60편): 튜닝이 나은 영상 30편, 나빠진 영상 18편, 같은 영상 12편이다. 전체 평균은 좋아졌지만, 모든 영상에서 좋아지는 것은 아니다.
- **흔들림 조건**:
  - 튜닝 전에는 두 모델 모두 대부분 64~68 BPM을 냈다. 끄덕임 주기에 고정된 것이다.
  - 마스크를 넣은 뒤에는 남은 오류가 끄덕임과 좌우 흔들림이 섞인 주파수(약 51·81 BPM)에 몰렸다.
  - 움직임 게이트(2%)는 이 조건의 추정을 100% 숨겼다. 어두움 조건에서는 0%를 숨겼다. 정지 얼굴의 흔들림은 0.2~0.6%였다.
- **창 길이**: 15~30초 창은 흔들림 조건에서 조금 나았지만, 휴식·운동 조건에서는 심박 변화를 늦게 따라가 나빠졌다. 그래서 10초를 유지했다.

## 바꾼 것

| 파일 | 내용 |
|---|---|
| `features/rppg/lib/hrEstimator.ts` | 새 추정기: 대역 통과(0.7~3Hz, 영위상), ME 버퍼의 스펙트럼, 얼굴 흔들림 마스크(1.5%), 직전 값 추적(σ 9 BPM, 다른 피크가 3dB 이상 높으면 이동), 흔들림 크기 반환 |
| `features/rppg/lib/rppg.ts` | `spectralPeak`를 `powerSpectrum`·`spectrumPeak`로 나눔(기존 결과 동일). 실험실 기록에 `fx`(튜닝 추정)·`fxMotion` 추가 |
| `features/rppg/engine/useMeRppg.ts` | `heartRateFromBvp` 대신 추정기 사용, 칼만 상자 좌표를 함께 넘김. 모델 초기화·워커·BlazeFace 실패 시 얼굴을 `inactive`로 해제하고 후속 프레임·늦은 응답을 차단해 감정 분석의 SSD 대체 경로를 복구함. rPPG 화면은 `error` 유지(`EngineFace` 타입 유지) |
| `features/rppg/engine/rppgGate.ts` | 새 상태 `motion`('움직임 감지'): 흔들림이 2%를 넘으면 숫자를 숨김 |
| `features/rppg/lib/labProtocol.ts`, 실험실 튜닝 칸·조건별 요약 | ME 버퍼 하나와 얼굴 상자 기록으로 `createHrTracker` 실행. 기존 CSV 열 뒤에 `fx_*`·`fx_motion` 추가. 예전 기록 복원 지원 |
| `features/rppg/lib/waveLog.ts`, 실험실 "파형 저장" | ME 출력·얼굴 상자 좌표·워치 값과 condition·eval·demo:start/end/cancel 표식을 JSON으로 저장(영상은 저장하지 않음) |
| `features/rppg/lib/demoCompare.ts`, 실험실 "시연: 워치 vs rPPG" | 1초 칸으로 30초 측정 후 워치 6초 지연 보정값을 추가 수집. 접촉 불량 워치 제외, 시연 중 조건·자동 평가 잠금. 회차별 결과를 `onmaum_rppg_lab_demo`에 저장하고 CSV 내보내기·기록 지우기 제공 |

FacePhys 자산·모델 선택 워커·체크박스·비교 칸·`fp_*` CSV 열·테스트는 이 PR에 포함하지 않는다. 공통 설정과 저장소 스키마는 바꾸지 않는다. 실험실 기록 계약은 선택적 `fx`·`fxMotion` 필드만 확장한다.

## 2026-11-04 실측

- 파형 재계산 평균 절대 차이: 같은 시각 비교 2.3 BPM, 워치 6초 지연 보정 1.1 BPM.
- 30초 측정 정상 4회: 지연 보정 평균 절대 차이 1.3 BPM, rPPG 표시 비율 67%. 실패 1회는 표시 비율 10%였다.
- 6초 보정과 움직임 기준은 잠정값이다. 위 실측은 제한된 시연 환경의 결과이며 다른 참여자·심박 변화 조건에서도 확인해야 한다.

## 남은 일

1. 실험실에서 조용히·말하며·움직이며 조건을 측정하고 "파형 저장"을 받는다. 실제 흔들림 크기로 2% 기준과 마스크 기준(1.5%)을 다시 정한다.
2. 위 실측을 바탕으로 다른 참여자·조명·심박 변화 조건에서도 "30초 측정"을 반복해 평균 차이와 표시 비율을 확인한다.
3. 측정 화면에 '움직임 감지' 상태가 새로 생겼다. 상태 문구는 `RPPG_STATUS_TEXT`로 자동 표시되지만, 화면 디자인 검토는 ④ UI 담당과 함께 한다.
